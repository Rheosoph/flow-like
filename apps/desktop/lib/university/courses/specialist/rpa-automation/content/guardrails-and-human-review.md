Extend the practice read with a proposed action on paper: “Acknowledge delayed order PO-001.” Do not connect an actual supplier action in this exercise.

Record the allowed operation, target record, expected state, reviewer and evidence. Permission to read a portal does not necessarily include permission to acknowledge or change its records.

For a review interface, use the optional Human Approval class in Interfaces and Pages. The production service must enforce actor permission and a single valid state transition before the effect; a visible Approve button is only the interaction.

Vision or LLM helpers can propose a target, plan or repaired selector. Validate the selected element, keep timeouts and attempt limits, and stop when the intended action cannot be established. A model suggestion should not silently broaden an allowed read into a write.

Minimize screenshots to the relevant element/region and apply the required handling policy before storing or sending them. Extracted interface content can contain names, addresses or credentials even when the flow only reads.

Before building, write four short statements: what starts the flow, what it transforms, which step changes state, and how you will inspect the outcome. Use a scratch folder, mailbox or service.

Define the repeated-run case. Replacing a file can be repeatable while sending the notification again is not. A seen flag can stop normal sweeps while a failure between draft creation and flagging still leaves a duplicate risk. Name each effect separately.

Build the chosen recipe as part of the capstone, then return to the final review. If a required account or runtime is unavailable, choose the file or local API recipe. The course does not require setting up unrelated services to finish.

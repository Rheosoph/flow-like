Build `normalize_text`, a node that trims and lowercases a string. It has two Boolean options and reports whether the text changed.

Use a WASM package when you need an independently versioned extension. A native Rust catalog contribution is compiled with the product and follows that release process. This course uses the maintained TypeScript Component Model template.

A node has a definition that exposes its identity, pins and capabilities, and a run function that computes values. The compiled package exports the definitions used by the catalog. A manifest description alone does not register a runnable node.

Internal node and pin names are stored in boards. Choose them before other people save the node in their flows. Friendly labels can change without intentionally renaming those identifiers.

The normalizer uses no network, storage or model host capability. Keep its permission declaration empty; resource tiers remain package configuration. More complex nodes need explicit capabilities and a runtime check, not just a successful unit test.

An App groups behavior with the interfaces, data, and access settings that make it usable. Use the **First Run** App from Welcome, or an existing practice App.

Plan a small **Equipment Register**: a person records an equipment label; a scheduled job later reports missing labels. Write down:

- One Flow for the manual action and one for the schedule, because they have separate triggers and failure handling.
- The interface that invokes each Flow.
- The shared records and files both need.

Keep connected steps of one operation in the same Flow. Layers can organize a crowded graph without introducing another invocation boundary.

**Check:** you can point to each responsibility in your plan without drawing data storage or team permissions as workflow nodes. For this course you will build only the manual action; persistent records come later in **Data in Flow-Like**.

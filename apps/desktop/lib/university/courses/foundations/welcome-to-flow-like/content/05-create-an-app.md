Create a private place to experiment before learning the rest of the interface.

1. Open **My Apps** and choose the create action, or choose **Create a new app** from Home.
2. Name the project **First Run** and choose **Offline**. Creating an online App requires signing in; offline is sufficient here.
3. Confirm with **Create Project**. Some versions of the dialog use **Create Flow** as its heading.
4. Open the App's first Flow in Studio. If there is no Flow yet, create one from the App's Flows workspace.

**Check:** First Run appears in My Apps and opens a canvas. Leave connectivity unchanged throughout this course.

An **App** holds your project. A **Flow** is one executable graph inside it. **Studio** is the editor for that graph. Later courses add data and interfaces to the same App boundary.

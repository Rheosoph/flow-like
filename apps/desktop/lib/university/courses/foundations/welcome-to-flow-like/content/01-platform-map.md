You have an App, a Flow, and a successful run. Locate the remaining boundary: your **Profile** is a bundle of model assignments and personal settings. It does not contain your Apps.

1. Return to My Apps and confirm First Run is present.
2. Open the active Profile menu in the sidebar. Find the current Profile name and its edit action; placement may differ between layouts.
3. If you already have another Profile, select it and reopen First Run. Otherwise leave the current Profile selected.

**Check:** switching Profile changes the active settings while First Run remains in My Apps. You do not need to create another Profile to finish this course.

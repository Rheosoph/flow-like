Open the active Profile menu in the sidebar and note which Profile is selected. Create a practice Profile or use one you already reserve for experiments.

1. Open **Explore Models**.
2. Pick a model whose configured capabilities include text input and text output.
3. Select **Add to Profile**. For a local model, also download its files and wait for completion before using it.
4. Open FlowPilot's model picker and select the assigned model through the Profile provider.
5. Send: `Reply with the single word cedar. Do not use tools or modify anything.`

**Check:** a response arrives from the selected model. Record the model name and whether it followed the one-word instruction. A different response is useful evidence about instruction following, not proof that profile assignment failed.

Downloading places files on this device. Adding to Profile makes the model available to compatible features. Signing in on another device can restore Profile settings without downloading the model weights there.

Open your two-node practice Flow and open FlowPilot in the board editor. Select Print Info and send:

```text
Explain what this selected node does and what starts it. Do not change the board.
```

**Check:** the response identifies Print Info's Message and its execution connection. The board should remain unchanged.

FlowPilot uses relevant visible context: the open board, layer, selection, and supplied run context. Select the object you mean before requesting a change. Global FlowPilot can coordinate work across workflows, interfaces, and data; this course starts with one board.

Choose a configured model in the provider picker. Profile models work in supported web and Desktop contexts. Signed-in external CLI providers are Desktop options. If your model struggles with a small edit, narrow the request and inspect its diagnostics before increasing scope.

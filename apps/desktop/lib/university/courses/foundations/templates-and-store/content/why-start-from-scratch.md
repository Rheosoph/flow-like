Open Explore and inspect one package listing. Record its ID, version, exported nodes, and purpose. Do not install a package just to complete this class.

Package state has three scopes: a version exists in the registry, code is installed on a device, and an App declares the version it needs. If nodes are missing, check the App's **Packages** screen as well as **Packages → Library**. The global Packages workspace may require Developer Mode.

**Check:** your notes distinguish the listing from a device installation and an App dependency. Updating a device copy does not by itself rewrite every App's linked version.

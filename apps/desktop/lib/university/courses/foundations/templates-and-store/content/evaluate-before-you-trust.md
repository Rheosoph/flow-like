Record:

- Which node you intend to use and whether this version exports it.
- Network hosts, storage scope, runtime values, or other permissions it needs.
- Author/source information and the evidence you would need before relying on it.

A verification badge records a review state. It does not establish that a package fits your data, environment, or future versions. A text formatter with unrestricted network access deserves investigation before installation.

If you choose a suitable package for a disposable App, install and link it, then verify that its documented node appears in the App's catalog. Otherwise finish with the written evaluation; the template lab uses standard nodes and needs no new dependency.

**Check:** you can explain each capability you would grant. When evaluating a whole App by forking, inspect the fork dialog: the owner decides which content the copy receives.

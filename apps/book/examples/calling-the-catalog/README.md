# Calling the catalog fixture

`catalog.flow` is the compact Chapter 8 example. It exercises a namespace alias, selected
imports, a qualified call, method form, renamed multi-output destructuring, and exact input-pin
names without requiring an external account or network call.

`packages/ast/tests/book_examples.rs` keeps the source parseable and in canonical renderer form.
Before publication, the example must also be reconciled with the release catalog, executed, and
captured in both authoring views.

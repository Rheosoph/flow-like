FlowScript gives one program two honest ways to be understood: readable source code and a
visible, typed workflow. The text is efficient when the system grows. The graph makes its
structure, execution, and failures accessible to builders, reviewers, operators, and domain
experts.

This is the book about that contract—and about the platform designed around it.

## Two applications carry the story

The first is **Incident Triage**, a small deterministic Flow that can be understood in a few
minutes. You will build it visually, read it as FlowScript, change it from both directions,
and diagnose a failure.

The second is **Incident Room**, a private runbook and document assistant. It grows the same
ideas into a complete application with data, retrieval, agent tools, interfaces, local
models, versions, and observable executions.

> The goal is not to turn every builder into an infrastructure specialist. It is to let
> people solve the problem they understand without silently creating the next 3 a.m.
> mystery.

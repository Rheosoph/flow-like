title: Platform administration
description: Operator tasks for audit records, starter Profiles, Home defaults, Explore, and payments
---

Platform administrators manage a hub's shared configuration and published
content. These screens require an online backend and the relevant global
permissions, including when opened from Desktop.

Choose the task you need:

| Task | Guide |
| --- | --- |
| Configure audit coverage, retention, keys, and verification | [Audit operations](/self-hosting/administration/audit/) |
| Prepare the Profiles offered to new users | [Manage starter Profiles](/self-hosting/administration/profiles/) |
| Deploy and publish shared Home defaults | [Publish default Home layouts](/self-hosting/administration/home-layouts/) |
| Prepare and publish storefront content | [Curate Explore](/self-hosting/administration/explore/) |
| Enable payments and operate recovery | [Payments rollout and recovery](/self-hosting/administration/payments/) |

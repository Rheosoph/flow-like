Flow-Like is a **visual workflow platform** for connecting data, services, and
user interfaces through typed workflows. Build and inspect the same logic as a
visual graph or as [FlowScript](/studio/flowscript/).

<Aside type="tip">
Start with [two nodes and one visible result](/start/getting-started/), then use
[Apps and core concepts](/apps/overview/) to understand ownership and entry points.
</Aside>

## Core Concepts

### Flows
A **Flow** is a directed graph of nodes. Execution connections control which
steps run, and data connections supply values. [Run logs](/studio/logging/)
record the available evidence according to the Flow's logging configuration.

### Nodes
**Nodes** are the building blocks. Their pins can carry input data, output
data, or execution control. Pure nodes have data pins and run when another node
needs their output; event nodes start execution. See [Nodes](/studio/nodes/).

### Type Safety
Every pin has a type. Flow-Like checks compatibility when you connect pins.
This catches wiring mistakes; it does not guarantee that an API will respond or
that an input value meets every business rule.

### Local-First
Flow-Like Desktop is designed to work offline. Start on your laptop, then connect to a hosted or self-managed environment when collaboration and remote execution are useful.

## What Can You Build?

- **ETL Pipelines**: Transform and move data between systems
- **AI Agents**: Embed LLMs, vector search, and reasoning models
- **Automations**: React to events, schedule tasks, orchestrate services
- **Data Processing**: Parse, validate, enrich, and route data
- **Custom Apps**: Build interfaces on top of your flows

Open **Settings → AI Models** to browse language, vision, embedding, and decision
models. With [Developer Mode](/start/developer-mode/) enabled, **Explore Models**
in the sidebar opens the same catalog:

![A screenshot of Flow-Like Desktop showing a preview of the Model Catalog](../../../assets/ModelCatalog.webp)

Downloading a model makes its files available on the current device. Assigning
it to a [Profile](/start/profiles/) makes it available to the Profile's AI
features and to compatible nodes in Studio.

For a local model, open the model card's menu and select **Download** if its
files are not present, then select **Add to Profile**. Hosted models do not
need a local model download. The catalog shows which models are already in
your Profile and whether a download or update is still in progress.

![Adding a model to the active Profile from the model catalog](../../../assets/AddingModelToProfile.webp)

Local models use disk space and execute on supported local hardware. Hosted
models and provider-backed models can instead require a configured provider or
account. The exact models shown depend on the current catalog and Profile.

Once assigned, select the model from compatible nodes in
[Studio](/studio/overview/) or from FlowPilot's model picker.

## Compare model quality

Language and vision model cards show **AA v5.0.1** when Artificial Analysis has
evaluated the model on that version of its Intelligence Index. **Est. AA v5.0.1**
marks an estimate calibrated from models with scores on both the older and current
versions. Open its details for the estimated range, evidence, and uncertainty.
The legacy catalog mixed index versions, so these estimates are not exact v4.3
conversions.
Models without a measured or calibrated result show **Not evaluated** or
**No matching model**. Older scores and unversioned estimates are not comparable.
Open the model to inspect individual benchmarks, the evaluated reasoning effort,
and the source. The benchmark's reasoning effort describes the evaluated
configuration; your provider settings may differ.

The index combines weighted benchmark tasks. Its task selection, languages, and
weights affect rankings, so use it alongside results that match your work.
See the [Artificial Analysis methodology](https://artificialanalysis.ai/methodology/intelligence-benchmarking)
for the scope of the evaluation. A score is not a universal measure of model quality.

Speech, embedding, image/video generation, forecasting, and decision model
cards can show a **Quality** rating from 0 to 100 for that category.
The **≈** symbol marks an estimate.
Compare speech-to-text models with other speech-to-text
models, for example. These editorial ratings describe expected output quality;
they are not accuracy percentages or measurements of performance on your
device. The detail view explains the criteria, estimated range, and language
or task limitations. When browsing one supported category, select
**Rating** in the sort menu to order its models by rating.

## Compare model prices

Hosted OpenRouter models show a **Provider price reference** with its check date,
source, and example workload. Image prices include the output resolution or
megapixel count. Speech prices distinguish characters from UTF-8 bytes, while
transcription prices use audio minutes. Provider list prices can differ from
Flow-Like plan usage and platform fees.

Read the routing notes for presets and models with several providers. A listed
price does not establish current availability. Unverified presets can show a
labeled reference for their linked model. When that model's current price or
billing unit cannot be verified, the catalog leaves the price unavailable.

## Custom API request parameters

For a custom HTTP chat or decision model, open **Connection → Advanced options**
and enter a JSON object in **Request parameters**. Use the provider's native API
field names. For example, an Anthropic model can set its output limit with:

```json
{
  "max_tokens": 8192
}
```

The Bit stores this object at `parameters.provider.params.request_params`.
Its values override fields generated by FlowPilot or a flow after the provider
SDK builds the request. Nested objects merge, while arrays, scalar values, and
`null` replace the existing value. This lets you add new API fields without
waiting for an SDK update. The provider still validates the resulting request.

Save the Bit before starting a new run to use the new parameters. Keep
credentials in the connection fields and custom headers. The app controls
streaming mode, so `stream` cannot be set here. Downloaded local models,
embedding models, and subscription or CLI connections do not use these request
parameters.

## Decision models

The **Decisions** category contains SystemOne models for classification,
scoring, and yes/no assessments. Connect **Find Decision Model** or **Load Bit**
to **SystemOne Choice**, **SystemOne Score**, or **SystemOne Noul** in Studio.
**Find Decision Model** selects an available model from the active Profile.
**Invoke SystemOne** asks
several named questions together. These models return typed answers and
probabilities and do not appear in chat model pickers. Device deployments also
require the model in the project's manifest dependencies; selecting a profile
model alone does not package it. See [Decision models](/topics/genai/models/#decision-models).

## Default Permission

Default permissions for the blob offload plugin – allows all commands.

#### This default permission set includes the following:

- `allow-blob-store`
- `allow-blob-get`
- `allow-blob-store-batch`
- `allow-blob-get-batch`
- `allow-blob-delete`
- `allow-blob-configure`
- `allow-blob-inc-refs`
- `allow-blob-dec-refs`
- `allow-sql-open`
- `allow-sql-exec`
- `allow-sql-close`
